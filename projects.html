Cemetery Escape Cemetery Escape is a 2D endless platformer game built in Unity using C#.
The player navigates through a haunted cemetery as a ghost, avoiding tombstone obstacles.

The project game features:
  • Unity gameplay mechanics
  • Custum SFX and background audio
  • Custom collision and trigger systems
  • Start and End game buttion functionality
  • Designed for future level difficulty implementation
